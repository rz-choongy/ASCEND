## App Navigation

```
Design a mobile app navigationfor a climbing-first workout tracker.

Bottom tabs:
- Home
- Planner
- Progress
- Settings

Home includes:
- Active session resume banner
- Today’s planned sessions (cardswithStart buttons)
- Persistent quick-start buttons:
Start Strength,Start Climb,Start Warmup,StartFree Session

Design style:
Fast, functional, data-focused.
Dark mode friendly.
Minimal decoration.
Large tap targets.

```

---

## Strength Workout Session Screen

```
Design a strength training session screen for a climber-focused workout app.

Requirements:
- Exercise name clearly visible
- Large + / – buttons for reps, weight, or time
- Copy last set behavior
- Swipe to mark set complete
- Rest timer always visible
- Undo button small and subtle
- Finish session button always visible

Style inspired by HEVY but more minimal.
Speed > visual flair.

```

---

## Climbing Session Screen

```
Design a climbing session logging screen.

Requirements:
- Large grade buttons (colors or V-grades)
- Sub-label showing grade range (e.g. V3–V5)
- Flash and Send buttons
- Session timer visible
- Undo button small
- Finish session always visible

Designed for one-handed use in a gym.
Extremely fast interaction.

```

## Session Summary Screen

```
Design a session summary screen for a workout app.

Requirements:
- List of logged items (sets or climbs)
- Tap to edit values or results
- Optional notes field
- Confirm button to save session

Minimal, calm, corrective UX.

```

## Progress Dashboards

```
Design progress dashboards for a climbing training app.

Climbing:
- Hardest send trend line (time vs V-grade)
- Stacked bar chart showing volume by grade buckets
- Session frequency

Strength:
- Total volume
- Session count
- Simple trends

Clean, data-forward, no clutter.

```
